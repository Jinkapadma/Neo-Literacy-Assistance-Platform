# Literacy Assistance Platform - Frontend Client (Phase 1)

Accessible, mobile-first React (Vite) single-page application built for neo-learners and adult literacy students.

## Key Features & Accessibility Innovations
- **Pedagogical Readability**: High-contrast theme, dyslexia-friendly font option (Lexend), scalable text sizes, and text-to-speech narration for any reading passage.
- **Multilingual Content Hub**: Fast language switcher driving dynamic content repository queries with native script rendering (English, Hindi, Spanish, etc.).
- **Curriculum Roadmap**: Modular progression tracking from foundational alphabet sounds to practical real-world comprehension.
- **Interactive Diagnostic Assessments**: Multi-type question runners (Reading comprehension passages, Word-picture associations, Spelling, Sentence reconstruction).
- **Automated Proficiency Benchmarking**: Immediate visual scorecards categorizing learners from Level 1 (Novice) to Level 4 (Fluent) with diagnostic strengths and improvement areas.
- **Secure Token Flow**: Memory-managed access tokens with automatic 401 axios interceptor refresh queue.

## Setup & Running

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Production build
npm run build
```
